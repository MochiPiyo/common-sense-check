# common-sense-check

実装や画面を見直し、常識的に考えて明らかにおかしい部分を見つけて減らすためのスキルです。表示名は「常識的チェックタイム」。

コーディングエージェント自身が見落としている、自明な問題や非効率な実装を点検します。見つけたら最優先で対応すべき大きな問題から取り組み、細かな問題も後から修正します。

## 使い方

スキルを導入した環境で、次のように依頼します。

```text
常識的チェックタイム。ここまでの作業を確認して、おかしいところを減らして。
```

範囲を絞る場合は、点検したい箇所を指定します。

```text
常識的チェックタイム。設定画面のGUIと、それに関係するコードを確認して。
```

範囲の指定がなければ、エージェント自身の作業範囲を点検します。実際の作業指示と注意点は [SKILL.md](SKILL.md) を参照してください。

## リポジトリの構成

- [SKILL.md](SKILL.md)：点検の目的、問題への対応順、作業範囲についての指示。
- [agents/openai.yaml](agents/openai.yaml)：表示名と短い説明。
